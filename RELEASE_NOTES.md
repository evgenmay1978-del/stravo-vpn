# STRAVO VPN 1.0.3

Исправления загрузки обычного VPN и запуска CDN. Один APK для Android-телефона и Android TV.

- По ссылке обычной или CDN-подписки MaestroVPN приложение загружает обе доступные части одного аккаунта. Вход по логину использует тот же путь. На TV загружается только обычный VPN.
- Сохранённые подписки обновляются при первом запуске новой версии. Если добавлен отдельный CDN-ключ, выбирается соответствующий режим вместо сообщения об отсутствии обычной подписки.
- Исправлена несовместимость CDN-конфига со встроенным ядром: неполная пара параметров идентификатора сессии обрабатывается так же, как в Xray. Сохраняется ALPN из Xray JSON-подписки.
- Раздельно добавленная подписка другого аккаунта сохраняется при автоматическом обновлении.

CDN требует отдельно купленных ГБ и активной обычной VPN-подписки. Доступ проверяет сервер.

Android 6.0+, ARM64 и ARMv7. Версия 1.0.3, код 4. Устанавливается обновлением поверх 1.0.2 с сохранением данных и подписи.

Исправления основаны на фактической выдаче сервера и исходниках встроенного ядра. Работа этой версии на физических телефоне и TV ещё требует подтверждения владельца; новые автотесты не запускались.
