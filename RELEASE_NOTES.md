# STRAVO VPN 1.0.4

Обычный VPN и CDN — две отдельные подписки.

- Импорт загружает только добавленную пользователем ссылку. Автоматический поиск и загрузка второй подписки, ошибочно добавленные в 1.0.3, удалены.
- Каждая подписка хранится и обновляется отдельно; добавление одной не удаляет другую. Вход по Maestro login загружает только обычную VPN-подписку.
- На главной и в профиле показано, что действительно добавлено: обычная VPN-подписка, CDN-подписка или две подписки. Общий заголовок сервера больше не создаёт впечатление, что обе части уже подключены.
- Исправление запуска XHTTP/CDN из 1.0.3 сохранено, как и выбор режима для отдельного CDN-ключа. На TV доступен только обычный VPN.

Добавьте обе свои ссылки по очереди через «Профиль → Добавить подписку». Для обычного подключения выбирайте «Обычный VPN», для CDN — «Свободный интернет».

CDN требует отдельно купленных ГБ и активной обычной VPN-подписки. Доступ проверяет сервер.

Android 6.0+, версия 1.0.4, код 5. Обновление устанавливается поверх предыдущей версии с сохранением данных и подписи. Работа обоих режимов на физическом устройстве ещё требует подтверждения владельца; новых автотестов нет.
