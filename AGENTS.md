# STRAVO VPN — правила репозитория

- Продукт: одно универсальное Android-приложение и один APK для телефона и Android TV.
- Обычный VPN доступен и на телефоне, и на TV. Режим «Свободный интернет» — только на телефоне;
  TV не показывает и не активирует его (fail-closed в `CapabilityPolicy`).
- Стиль: бумага + графит, чертёжные линии, сдержанный изумрудный акцент. Без щитов, замков и пейзажей.
- Любая вёрстка — адаптивная Compose-раскладка; абсолютные координаты и «картинка-скриншот» запрещены.
- GitHub Actions — каноничная среда сборки. Локальные `assemble` на слабой машине владельца не запускаем.
- Никогда не логировать и не коммитить: URL подписок, UUID, ключи, токены, пароли, полные VPN-конфиги.
- Не менять прод-серверы, платежи, OTA и данные клиентов из этого репозитория.
- Автотесты не добавляются и не запускаются без отдельного разрешения владельца.
- Если VPN-ядра или pairing-API нет — не имитировать успех: показать честное состояние и описать контракт.
