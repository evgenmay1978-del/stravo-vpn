# STRAVO VPN local rules

- The product is one universal Android project and APK for Android phones and Android TV.
- Ordinary VPN is available on phone and TV.
- White-list mode is available only on phones; TV must not expose or activate it.
- GitHub Actions is the canonical environment for Android builds and heavy validation because the owner’s computer is weak. Do not run local Gradle assemble tasks unless explicitly requested.
- Incy is a functional and visual reference only; do not copy closed source or proprietary assets.
- Keep the professional paper-canvas, graphite, map, compass, and restrained colored-pencil visual system on every screen.
- Never log or commit subscription URLs, UUIDs, keys, tokens, credentials, customer identifiers, or complete VPN configurations.
- Do not change production servers, payments, OTA, or existing customer data from this repository without separate explicit authorization.
- Do not add or run automated tests unless the owner explicitly authorizes them.
