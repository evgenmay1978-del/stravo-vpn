# STRAVO Design Kit

Комплект для реализации Android + Android TV.

## Стиль
Чёрно-белый карандаш/графит на светлой бумаге.
Emerald `#2FBF8F` — только функциональный акцент.

## Главное
- `docs/STRAVO_CODEX_MASTER_PROMPT.md` — полное задание Codex.
- `COPY_TO_CODEX.txt` — то же самое, удобно копировать целиком.
- `blueprints/` — мобильная и TV-компоновка.
- `assets/vectors/` — исходные SVG.
- `assets/textures/` — бумага/графит.
- `design_tokens.json` — размеры/цвета/правила.

## Telegram
По текущему контексту используется:
`@MaestroSecureVPN_bot`

Имя бота специально вынесено в конфигурацию и меняется одной строкой.

## QR-перенос подписки
Добавлен полноценный сценарий Phone → Android TV:
- TV генерирует одноразовый QR;
- телефон открывает Telegram-бот;
- пользователь подтверждает;
- подписка автоматически импортируется на TV;
- секрет подписки в QR не помещается.

См. `docs/STRAVO_QR_SUBSCRIPTION_PAIRING.md`.
