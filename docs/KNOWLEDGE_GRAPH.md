## Постоянные связи

- STRAVO → один APK → Android телефон + Android TV.
- Телефон → обычный VPN / CDN; TV → только обычный VPN → `CapabilityPolicy`.
- Ordinary/CDN → независимые явно добавленные источники → `SubscriptionImporter`
  → `SubscriptionRepository` → `HomeUiState`. Не выводить второй URL из первого.
- Карандашный референс владельца → общие PencilSurface/PencilIcon/бумажные ассеты
  → все экраны. Меню и действия сохраняются.
- Разработка → только приложение → GitHub `evgenmay1978-del/stravo-vpn`.
- Сборка → GitHub Actions. Без локального Gradle и без новых автотестов.
- Серверы/SSH/deploy/платежи/OTA → вне разрешённого объёма.
- Сборка и подпись → доказательство APK; не доказательство VPN на устройстве.
- Новое разрешение 21.09 → полноценная реализация Android/TV → сохранить Maestro login
  → серверы неизменны → [план/реестр](IMPLEMENTATION_ROADMAP.md).
- Multi-source → importer/source IDs → repository → общий SubscriptionManager → phone/TV.
- Network preferences → validation → NetworkPolicy → fresh core config → переподключение.
- User connect → source-scoped group → URL-test/selector → health probe → честный UI.
- Backup → password-encrypted file → user-confirmed restore → stop VPN → reload; без auto-start.

1. Выбор системных приложений → AppsScreen скрывает их по умолчанию;
   QUERY_ALL_PACKAGES уже есть. SettingsRepository сохраняет выбор, но активный

   не утверждать, что физический сценарий воспроизведён.
2. Смена сервера → LocationSelected меняет только HomeUiState.location → ядро
   не получает новый узел. StravoVpnService также не сериализует повторный запуск
   со старым ядром. Исправить полный путь выбора/остановки/запуска.
3. Хедер подписки → profile-title читается → сохраняется по виду подписки →
   профиль скрывает его общим названием. Остальные метаданные поддержаны неполно.
   Показывать данные именно выбранного источника; сверяться с публичными INCY/HAPP docs.

## Исправления в исходниках 1.0.7 (8)

- Системные приложения → видимы по умолчанию; настройка фильтра сохраняется;
  выбранные/найденные поиском не скрываются. Android checkbox semantics и зона 48dp.
- Изменение appMode/apps → обновление активного туннеля после короткой паузы выбора.

- LocationSelected → engine.connect → последовательная очередь StravoVpnService →
  закрытие старого ядра/TUN → запуск нового. Устаревшие запросы не публикуют Connected.
- SubscriptionMetadata → HTTP headers или inline fallback/base64 → название, описание,
  объявление, расход/лимит/срок → отдельная модель ordinary/CDN → выбранный источник UI.
  Данные отображаются как текст; routing/autorouting и дополнительные URL не исполняются.
- Перезапуск приложения → сохранённые метаданные; версия разбора 4 → обновление только
  ранее добавленных источников. Публичные форматы:
  https://docs.incy.cc/subscription-format/ и
