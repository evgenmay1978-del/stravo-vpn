# STRAVO VPN — интерфейс по референсу владельца

Цель: универсальный APK с бумажным интерфейсом телефона и TV, объёмным графитовым медальоном и тонкой изумрудной подсветкой. Направление подтверждено владельцем 19.09: переделываем именно STRAVO, выглядеть должно как присланный макет.

- Общие компоненты Compose: светлая бумага #F3EFE5, графит #26332F, тёмный изумруд #246B54; антиква в логотипе, спокойный гротеск для управления, тонкие рамки и небольшие радиусы.
- Главная телефона: знак над названием, медальон, статус, компактные карточки локации/профиля, режим, реальные метрики и быстрое подключение. Диагностика раскрывается отдельно.
- TV: тёмная боковая навигация, светлый контент, крупный медальон, читаемый фокус D-pad. Режим белых списков остаётся только на телефоне.
- Профиль, настройки, локации, QR используют те же карточки, кнопки и типографику. Иллюстрация отдельным прозрачным ресурсом; весь текст и управление остаются нативными.
- Не менять ядро, конфиги подключения, импорт, платежи, серверы, токены и OTA. Новое изображение разрешено прямым референсом владельца, включая карандашные горы по краям (уточняет старое ограничение без пейзажей).
- Сборка в GitHub Actions с существующим ядром из кэша и постоянной подписью; без автотестов. Просмотр реального интерфейса на доступном Android, передача APK.

Порядок: общие компоненты → композиции телефона/TV → сборка → просмотр → APK и краткая фиксация результата.
