# Чек-лист приёмки

Отмечается вручную: автотесты владелец не разрешал, поэтому проверка идёт на устройстве/эмуляторе.

## Сборка

- [ ] GitHub Actions: workflow `Android build` зелёный
- [ ] Артефакт `stravo-vpn-debug` содержит `app-debug.apk`

## Телефон

- [ ] Приложение запускается, стартовый статус «ГОТОВО К ПОДКЛЮЧЕНИЮ»
- [ ] Нажатие на медальон даёт понятную ошибку об отсутствующем ядре (без фейкового «подключено»)
- [ ] «Быстрое подключение» открывает Telegram, при отсутствии — браузер, иначе копирует ссылку
- [ ] Экран локации: фильтр «Рекомендовано/Все», поиск, выбор локации сохраняется
- [ ] Профиль: подписка, «Подключить ТВ», поддержка
- [ ] Настройки: протокол, переключатели, язык, версия
- [ ] Ни один элемент не выходит за экран на узком экране и при fontScale 1.3
- [ ] Поворот экрана не теряет выбранный раздел и настройки
- [ ] Кнопки не меньше 48dp, у иконок есть contentDescription

## Подписка

- [ ] Профиль → Добавить подписку: вставка ссылки из буфера добавляет серверы
- [ ] Ввод ключа vless:// (включая type=xhttp), anytls://, hysteria2:// даёт узел в «Локациях»
- [ ] Ссылка без доступа к сети показывает «Не удалось скачать подписку», без выдуманного успеха
- [ ] Скан QR с ключом добавляет подписку (Профиль → Добавить подписку → Сканировать QR)
- [ ] «Удалить подписку» очищает узлы и возвращает витрину локаций
- [ ] В logcat нет ссылок подписки, UUID, паролей и ключей Reality
- [ ] Подпись «Протокол» в Настройках показывает Авто (рекомендуется) по умолчанию

## Android TV

- [ ] Запуск через LEANBACK_LAUNCHER, баннер отображается
- [ ] Весь интерфейс проходится только D-pad, фокус всегда виден
- [ ] «Быстрое подключение» открывает экран переноса подписки с QR
- [ ] Обратный отсчёт уменьшается, «Обновить QR-код» создаёт новый токен
- [ ] Режим «Свободный интернет» на TV не отображается и не активируется
- [ ] Текст не выходит за safe area 48dp

## Иконка и бренд

- [ ] Adaptive icon не обрезается масками (foreground/background/monochrome раздельно)
- [ ] TV banner 320×180 на месте
- [ ] В интерфейсе нет щитов, замков и пейзажей, изумрудный — только акцент

## Безопасность

- [ ] В логах нет URL подписок, UUID и ключей
- [ ] QR содержит только токен переноса
- [ ] Срок жизни токена — 5 минут, повторный claim отклоняется (проверяется после появления API)
