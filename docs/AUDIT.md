# Аудит и очистка репозитория

Дата: 2026-09-17.

---

## Что было в репозитории до очистки

Default-ветка `feature/stravo-vpn-mvp`, вторая ветка `building-a-pc-9dc8c`.
В корне лежали артефакты сборки и рабочие файлы, которых в публичном репозитории быть не должно:

| Файл | Почему плохо |
|---|---|
| `app-debug.apk.b64` (≈14,8 МБ) | бинарный APK в base64 внутри репозитория |
| `local.properties` | локальные пути SDK |
| `hs_err_pid*.log` (3 файла) | дампы падений JVM |
| `.gradle/`, `.kotlin/`, `app/build/**` | кэш и результаты сборки (902 файла, +218k строк) |
| `REBUILD.txt`, `RELEASE.md` | сторонние заметки без отношения к продукту |
| `.github/workflows` | все workflow были удалены — CI отсутствовал |

Дополнительно: `app-debug.apk.b64` и кэши раздували репозиторий до ~25 МБ.

---

## Что сделано

1. Текущее состояние обеих веток сохранено локально в виде tarball-архивов:
   `C:\Users\User\Desktop\stravo_backup_20260917\*.tar.gz` (по ≈22 МБ каждый).
2. История репозитория заменена **одним корневым (orphan) коммитом**: старые ветки удалены,
   мусор сборки в дерево не попадает.
3. Добавлен `.gitignore`, который закрывает `build/`, `.gradle/`, `.kotlin/`, `local.properties`,
   `*.apk`, `*.keystore`, `hs_err_pid*.log`, `.secrets/`, `*.env`.
4. Возвращён CI: `.github/workflows/android.yml` собирает debug APK и публикует артефакт.
5. Исходный дизайн-комплект перенесён в `design-kit/` (токены, blueprint'ы, SVG, текстуры, задание) —
   в том числе reference-скриншот экранов.
