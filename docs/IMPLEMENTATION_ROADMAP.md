# STRAVO — полноценный Android/TV клиент, 21.09.2026

Основание: владелец после сравнения INCY/HAPP поручил реализовать полноценное
приложение для Android и Android TV, сохранить авторизацию логином, не трогать
серверы и вести контекст/граф. Это разрешение на реализацию, не на серверные операции.
Сравнение: [исследование](2026-09-21-competitors-vless.md).

## Продукт и границы

Один APK и общие данные/ядро/настройки. Телефон ordinary/CDN; TV только ordinary.
Карандашный визуал и существующие пункты навигации сохраняются, функции добавляются
в профиль, локации и настройки. Maestro login сохраняется без изменения API.
Ни один второй URL подписки не выводится из первого. Настройки и ключи мигрируют
без очистки данных. Серверы, SSH, платежи, OTA и чужие сервисы вне задачи.
Автотесты не разрешены владельцем; сборка только GitHub Actions, локальных Gradle нет.
Не включать VPN на устройстве владельца автоматически.

## Архитектура и порядок

Развиваем существующий клиент, а не подменяем его оболочкой конкурента. Это
сохраняет login/CDN/подпись и визуал. Альтернатива полной замены ядра требует
отдельной совместимости всей подписки и не считается готовым решением сама по себе.
Данные источника имеют независимый id; узел связан с источником; secret URL/конфиг
остаются в SecretStore. UI читает источники и выбранный sourceId.
Настройки сети валидируются до сохранения. Проверка работоспособности выполняется
приложением только в рамках пользовательского подключения/явного действия;
агент не запускает сетевые пробы на серверы.

- [ ] 1. Импорт/протоколы: REALITY password/publicKey, полнота VLESS/Vision полей,

  Файлы: PanelSubscription, SubscriptionLinkParser, VpnProtocol, SingBoxConfigBuilder.
- [ ] 2. Подписки: несколько источников одного вида, выбор, rename, enable/disable,
  удаление/обновление одного источника, интервал; безопасная миграция 1.0.7.
  Файлы: SubscriptionImporter/Repository/Metadata, модель источника; UI интегрирует основной агент.
- [ ] 3. DNS/маршруты: сохраняемые и реально применяемые DNS, domain/IP direct/proxy/block,
  настройки подключения; общие адаптивные контролы телефона/TV.
  Файлы: SettingsRepository, NetworkPolicy, ConnectionPreferences.
- [ ] 4. Жизненный цикл VPN: статус доступности отдельно от поднятого TUN, проверка
  через ядро, автовыбор/замена недоступного узла, сохранение выбранного источника/узла,
  восстановление разрешённого пользователем подключения и boot-поведение.
  Файлы: StravoVpnService, SingBoxVpnEngine, TunnelStats, StravoViewModel.
- [ ] 5. Phone/TV UI: управление источниками, поиск/сортировка/пинг локаций, общие
  сетевые настройки/журнал. TV не получает CDN даже через импорт/восстановление.
- [ ] 6. Резервное копирование с шифрованием и пользовательским выбором файла,
  восстановление без логирования секретов; дополнительные протоколы/полный JSON —
  по фактической поддержке ядра, не по фиктивным пунктам меню.
- [ ] 7. Сборка изменённого APK в Actions, подпись/версия/артефакт, фиксация
  оставшихся ограничений. «Не уступает» не заявляется по одной компиляции.
- [ ] 8. Добавлено владельцем в ходе работы: автоматическое обновление STRAVO
  Android/TV из GitHub Releases. Проверка версий, Wi-Fi download, SHA256+package+
  signing certificate, системная установка с подтверждением. Без серверного OTA.

## Контракты параллельной реализации

- Подписки: новая модель SubscriptionSource(id, service, subscription, enabled, name,
  updatedAt, updateIntervalHours), repository.sources StateFlow и sourceId у SubscriptionNode.
  Репозиторий предоставляет select-independent data; parent отвечает за UI/selectedSourceId.
- Сеть: SettingsRepository сохраняет новые поля; NetworkPolicy.apply(config, settings)
  изменяет только DNS/route; parent передаёт settings после построения конфигурации.
  ConnectionPreferences(viewModel, modifier) — общий UI без новой глобальной навигации.
- Протоколы: сохраняется build(link, variant, directMode, apiSecret).
  Public outboundFor(link, tag) даёт один proxy outbound для группового выбора в ядре.
- Основной агент владеет AppContainer, ViewModel, HomeUiState, VpnService, roots,
  model ConnectionState и компонентами экранов; перед чужими файлами согласует границу.
